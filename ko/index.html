AnberTech 소개

AnberTech는 일상의 문제를 간단하게 해결하는 모바일 앱과 웹 도구를 만듭니다. 앱은 App Store와 Google Play에 출시되며, 각 앱에는 무료 웹 도구와 가이드가 있는 전용 사이트가 있습니다. Kuafix와 Formal Nöbet Çözücü는 튀르키예를 위해 튀르키예어로 만들어졌고, TurnuVolt와 성적 계산기는 여러 언어로 제공됩니다.

자주 묻는 질문

AnberTech 앱은 무료인가요?

성적 계산기와 Formal Nöbet Çözücü는 무료입니다. TurnuVolt는 1회 구매입니다. Kuafix는 무료로 다운로드할 수 있고 고객은 무료로 이용합니다. 미용사 패널은 1개월 무료 체험 후 Premium 구독이 필요합니다.

각 앱은 무엇에 쓰나요?

Kuafix는 미용실·바버샵 예약, TurnuVolt는 모든 게임의 대회·리그 대진표 작성, 성적 계산기는 평균, 기말고사 필요 점수, 학점 계산, Formal Nöbet Çözücü는 의사의 월간 당직표 작성에 씁니다.

설치하지 않고 써 볼 수 있나요?

네. TurnuVolt 사이트에는 무료 대진표 생성기가, 성적 계산기 사이트에는 기말 점수·평균·학점 무료 계산기가 있습니다. Formal Nöbet Çözücü는 원래 브라우저에서 작동합니다.

어떤 언어를 지원하나요?

TurnuVolt는 33개 언어, 성적 계산기는 17개 언어를 지원합니다. Kuafix와 Formal Nöbet Çözücü는 튀르키예어입니다.
